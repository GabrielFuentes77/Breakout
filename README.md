# Breakout

Projeto acadêmico desenvolvido com HTML5, CSS3 e JavaScript puro.

## Estrutura

- `index.html`: estrutura e telas do jogo
- `css/style.css`: aparência e responsividade
- `js/game.js`: regras, colisões, controles, pontuação e áudio
- `INICIAR-JOGO.cmd`: inicia um servidor local no Windows

## Executar

Abra `index.html` diretamente no navegador ou dê dois cliques em `INICIAR-JOGO.cmd`.

No VS Code, abra a pasta `C:\Projetos\Breakout`.
